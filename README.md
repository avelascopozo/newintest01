# newintest01

## Layout prototype
The HTML dump includes a prototype grid layout inspired by the reference screenshot. The styles are scoped to the `layout-prototype-grid` class on the `<body>` tag, so you can toggle the look by adding/removing that class.

Open `Fashion Trends for Women _ P&B.html` (or the `index.html` copy) in a browser to preview the grid. For live reloading during experimentation, run a local server (for example: `python -m http.server`) and open `http://localhost:8000/` which serves `index.html` by default.
